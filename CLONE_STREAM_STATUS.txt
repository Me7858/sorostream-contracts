================================================================================
                         AUTHORIZATION RULES
================================================================================

WHO CAN CLONE?

✅ Stream sender
   - Original creator of source stream
   - Can clone to any recipient

✅ Delegate (if set via set_delegate)
   - Authorized to act as sender
   - Can clone like sender

❌ Anyone else
   - Returns NotAuthorized error
   - Cannot clone streams

================================================================================
                         USE CASES ENABLED
================================================================================

1. MONTHLY RECURRING STREAMS
   ├─ Create stream for January
   ├─ Clone for February (same params)
   └─ Clone for March, April, etc.

2. MULTI-RECIPIENT CAMPAIGNS
   ├─ Create template stream
   └─ Clone 99 times with recipient override
      └─ One command, 100 identical streams

3. CROSS-TOKEN STREAMS
   ├─ Have stream with Token A
   └─ Clone with token override → Token B
      └─ Same rate, different token

4. RATE ADJUSTMENTS
   ├─ Current stream: 1000 USDC/month
   └─ Clone with rate override: 2000 USDC/month
      └─ Double the rate, same recipient

5. TESTING/STAGING
   ├─ Production stream created
   └─ Clone for staging with recipient override
      └─ Same params, different test recipient

6. GOVERNANCE/DELEGATION
   ├─ Sender creates stream
   ├─ Delegates cloning rights via set_delegate
   └─ Delegate can clone streams as needed
