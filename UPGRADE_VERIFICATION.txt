FUNCTION SIGNATURE:
  pub fn upgrade(env: Env, new_wasm_hash: BytesN<32>) -> Result<(), StreamError>

CODE:
  1. let admin = read_admin(&env).ok_or(StreamError::NotInitialized)?;
  2. admin.require_auth();
  3. env.deployer().update_current_contract_wasm(new_wasm_hash);
  4. Ok(())

AUTHORIZATION MECHANISM:
  Layer 1: Retrieve admin address from persistent storage
  Layer 2: Require cryptographic signature from admin
  Result: Only admin with correct key can upgrade

                      USAGE INSTRUCTIONS
================================================================================

TO UPGRADE THE CONTRACT:

1. Build new code
   $ cargo build --target wasm32v1-none --release

2. Get WASM hash
   $ sha256sum target/wasm32v1-none/release/sorostream_stream.wasm

3. Test on testnet
   $ stellar contract invoke \
       --network testnet \
       --id <TESTNET_CONTRACT> \
       -- upgrade \
       --new_wasm_hash <HASH>

4. Upgrade mainnet
   $ stellar contract invoke \
       --network public \
       --id <MAINNET_CONTRACT> \
       -- upgrade \
       --new_wasm_hash <HASH>

5. Verify success
   $ stellar contract invoke \
       --network public \
       --id <MAINNET_CONTRACT> \
       -- get_version
